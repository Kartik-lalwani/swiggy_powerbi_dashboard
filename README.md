# swiggy_powerbi_dashboard
# 🍔 Swiggy Business Dashboard: Restaurant & Rating Analysis

## 📌 Project Overview
This repository contains an interactive Power BI dashboard analyzing a Swiggy dataset sourced from Kaggle. The project visualizes key performance indicators (KPIs) for nearly 1,000 restaurants across various cities, uncovering trends in customer ratings, pricing, and restaurant distribution to provide actionable business insights.

## 🛠️ Tools Used
* **Data Cleaning & Transformation:** Power Query
* **Data Visualization & Modeling:** Microsoft Power BI

## 💡 Key Business Insights
Based on the dashboard visualizations, several key trends were identified:

•	Created an interactive Power BI dashboard using a Kaggle dataset to track the performance and customer ratings of 980+ Swiggy restaurants.

•	Cleaned the raw data before building the dashboard. Fixed text formatting errors and filtered out missing values to make sure all the calculations were accurate.

•	Implemented KPIs for overall average rating, and top-rated restaurants exceeding 4 stars. Designed visuals highlighting top 5 restaurants by average rating and used a scatter plot to see if there was a connection between how much a meal costs and the rating it gets.

•	Analyzed the data to uncover the real story behind customer reviews, proving that paying premium prices doesn't guarantee a top-tier meal, and identified budget friendly hidden gems  that consistently outperform their expensive competitors.

## 🗄️ Dataset
The data used in this project was sourced from Kaggle. It contains restaurant names, locations, costs, and customer ratings for Swiggy listings.
